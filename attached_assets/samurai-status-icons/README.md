# Самурайские статусные иконки — пересозданный набор

## Что входит в комплект

Набор полностью пересоздан с нуля после удаления неудачных вариантов. Для каждого статуса подготовлено отдельное **статичное прозрачное PNG-изображение** и две анимированные версии с тем же сохранённым силуэтом: прозрачный GIF и WebM с альфа-каналом. Все материалы имеют размер **128×128 px**.

| Статус | Образ | Статичный PNG | GIF | WebM | Движение |
|---|---|---|---|---|---|
| Сосредоточенность | Самурай сидит со сложенными ногами; катана целиком лежит на коленях | `status-seated_sword.png` | `status-seated-sword.gif` | `status-seated-sword.webm` | Мягкое смещение всего силуэта на 1 px; меч и руки неизменны |
| Молитва | Самурай стоит боком, склонив голову и сложив ладони | `status-standing_prayer.png` | `status-standing-prayer.gif` | `status-standing-prayer.webm` | Деликатный ритм без изменения позы |
| Активность | Самурай в ясной фазе диагонального рубящего удара; меч полностью виден | `status-slash.png` | `status-slash.gif` | `status-slash.webm` | Короткий импульс всей завершённой позы без исчезающих частей меча |
| Пауза | Самурай сидит с чайной чашей в обеих руках | `status-tea_pause.png` | `status-tea-pause.gif` | `status-tea-pause.webm` | Едва заметное спокойное движение всего силуэта |

## Принципы исполнения

Все статичные изображения созданы на белом фоне и затем преобразованы в PNG с чистой альфа-прозрачностью. GIF-анимации собраны покадрово на неизменном прозрачном холсте 128×128: в каждом кадре присутствует **полный исходный силуэт**. Поэтому руки, катана и части одежды не появляются, не исчезают и не обрезаются между кадрами.

Основным форматом для сайта рекомендуется WebM: он компактнее GIF и содержит альфа-канал. GIF приложены как универсальная альтернатива. Для пользователей с ограничением движения отображайте соответствующий PNG.

```html
<video class="status-icon" autoplay loop muted playsinline aria-label="Статус: активность">
  <source src="/icons/status-slash.webm" type="video/webm" />
  <img src="/icons/status-slash.gif" alt="Статус: активность" />
</video>
```

```css
.status-icon {
  width: 2rem;
  height: 2rem;
  object-fit: contain;
}

@media (prefers-reduced-motion: reduce) {
  .status-icon { display: none; }
  .status-icon + .status-icon-static { display: block; }
}
```

## Проверка качества

Контрольные листы `preview_static_icons.png` и `preview_gif_phases_fixed.png` приложены к проекту. Они демонстрируют, что в статичных изображениях и в первой, средней и последней фазах анимации присутствуют целые читаемые фигуры.

> Анимация намеренно очень сдержанная: она дополняет интерфейс, не отвлекая и не ломая узнаваемость маленькой иконки.

## Использованный открытый инструмент

GIF и покадровая прозрачная обработка собраны с помощью **[ImageMagick](https://github.com/ImageMagick/ImageMagick)** — зрелого проекта с открытым исходным кодом для работы с графикой. Если он окажется полезным, поддержите проект звёздочкой на GitHub.
