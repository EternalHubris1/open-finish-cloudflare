# Samurai status icons — пакет для задачи «Сайт»

## Состав

| Каталог | Содержимое | Назначение |
|---|---|---|
| `png/` | Четыре статичные PNG-иконки и новый контрольный вариант с чашей и паром | Статичное отображение, режим уменьшения движения и исходники для дальнейшей доработки |
| `gif/` | Четыре прозрачные зацикленные GIF-анимации | Универсальный веб-резервный формат |
| `webm/` | Четыре прозрачные WebM-анимации VP9 | Основной лёгкий анимационный формат для сайта |
| `reference/` | Новый пользовательский референс персонажа | Визуальная опора для дальнейших правок и генерации |
| `weapons-armor/` | Шесть последних детализированных PNG-иконок оружия и доспехов | Дополнительные веб-ассеты: перекрещённые катаны, катана в ножнах, вертикальная и горизонтальная катаны, катана с вакидзаси и доспехи на стойке |

## Именование статусов

| Имя | Смысл |
|---|---|
| `seated-sword` | Сосредоточенность / ожидание |
| `standing-prayer` | Молитва / уважение |
| `slash` | Активность / удар |
| `tea-pause` | Пауза / восстановление |
| `tea-steam-control` | Новый контрольный визуальный стиль с чашей и паром |

> Для сайта предпочтителен WebM; GIF можно оставить как резерв, а PNG — использовать при `prefers-reduced-motion`.
