# Design skill library

Catalog reviewed on 2026-08-14. Use skills together by responsibility; no single skill defines the design language.

## Core

| Skill | Use in Design Lab |
| --- | --- |
| `open-finish-design-lab` | Orchestrates the branch workflow and protects cumulative design memory. |
| `ask-nodumb` | Frames product, UX, screen, flow, and art-direction questions before producing solutions. |
| `system-feedback` | Reviews actions plus loading, empty, error, success, undo, and edge states. |
| `nodumb` | Challenges an expensive direction before a large redesign or systemic implementation. |

## Visual production and validation

| Skill | Use in Design Lab |
| --- | --- |
| `control-in-app-browser` | Inspect and visually test responsive, interactive product states in a browser. |
| `visualize` | Create inspectable in-conversation comparisons, interface studies, diagrams, and data-visualization explorations when a visual materially improves the decision. |
| `imagegen` | Explore original raster imagery, illustration, texture, or art-direction assets; do not use it to replace code-native UI, SVG, or an established icon system. |
| `sites-building` | Available for a future Sites-based surface; inactive for this repository because it has no `.openai/hosting.json` and already has its own application structure. |

There is currently no dedicated installed skill for typography, color theory, motion systems, accessibility auditing, icon systems, or general visual QA. Until one becomes available, cover these through the Design Lab process, authoritative research, browser inspection, and the review checklist. Re-evaluate this catalog when the environment changes.
