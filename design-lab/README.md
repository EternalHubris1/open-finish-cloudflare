# Open Finish — Design Lab

This directory is the durable memory and operating system for product design in Open Finish.

Open Finish is a **Personal Operating System for long-term mastery**. It is not framed as a task manager, habit tracker, productivity app, or admin dashboard. The design language should make that distinction visible in a single screenshot without imitating another product's identity.

## Sources of truth

- [`DESIGN_BIBLE.md`](DESIGN_BIBLE.md) — the current approved design language.
- [`DECISIONS.md`](DECISIONS.md) — the permanent history of approved and superseded decisions.
- [`PROCESS.md`](PROCESS.md) — the required research, concept, review, and memory workflow.
- [`SKILLS.md`](SKILLS.md) — the design skills available in this environment and when to use them.

The five dashboard concepts in [`../design-exploration/README.md`](../design-exploration/README.md) remain experiments. None is canonical until explicitly selected and recorded.
