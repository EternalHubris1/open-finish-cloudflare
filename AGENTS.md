# Open Finish — Design Lab

This branch is the permanent product-design laboratory for Open Finish. Keep work focused on UX, UI, art direction, interaction, motion, data visualization, responsive behavior, accessibility, and the design system. Do not expand into backend, infrastructure, deployment, databases, authentication, APIs, or business logic unless a constraint directly changes the user experience.

Before design work:

1. Read `design-lab/DESIGN_BIBLE.md`, `design-lab/DECISIONS.md`, and `design-lab/PROCESS.md`.
2. Use the project skill at `.agents/skills/open-finish-design-lab/SKILL.md`.
3. Treat existing mockups and screenshots as experiments unless the Design Bible marks them approved.

For major decisions, work in this order: research → compare approaches → explain trade-offs → produce distinct concepts → recommend and select → prototype → review → iterate → record the approved decision.

Design implementation in this branch means prototypes, visual explorations, interaction studies, and design-system artifacts. Do not ship unrelated product functionality from this branch.

Never replace an approved design language silently. Evolve it, record what changed and why, and keep superseded decisions in the history.
